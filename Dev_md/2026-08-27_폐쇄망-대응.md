# 폐쇄망에서 열리게 만들기 — 전 리포 정비

**날짜** 2026-08-27 · **대상** hd-01~08 · hd-project01~11 · 13~16 (24개 리포 / 29개 화면)

수업·실무 환경이 인터넷이 끊긴 사내망이므로, 화면이 바깥을 부르지 않아야 한다.

## 왜 이게 조용한 사고인가

바깥을 부르는 태그 하나가 페이지 전체를 멈춘다.
`<link rel=stylesheet>` 와 `<script src>` 는 화면 그리기·파싱을 **막는다.**

폐쇄망에서 그 요청은 **거절되는 게 아니라 응답 없이 기다리다 시간이 다 되어야** 끝난다.
그동안 화면은 하얗다. 몇 초에서 수십 초.
"안 열린다"고 보이지만 실제로는 열리는 중이고, 그래서 원인을 찾기 어렵다.

그리고 이 증상은 **인터넷이 되는 곳에서는 절대 재현되지 않는다.**

## 고친 것

| | 무엇 | 어디 | 어떻게 |
|---|---|---|---|
| ① | Pretendard 글꼴 CDN | hd-theme.css 사본 14개 + hd-05 | 지움 — 뒤에 있던 OS 기본 글꼴 목록이 이어받는다 |
| ② | Google Fonts | hd-01·06·07·project09 | 지움 (위와 같음) |
| ③ | supabase-js CDN | 9곳 | UMD 파일을 `lib/` 에 동봉 |
| ④ | React·Babel CDN | hd-05 | `lib/` 에 동봉 (3.9MB) |
| ⑤ | 사진 14장 (unsplash) | hd-01 | `img/` 에 동봉 (2.8MB) |
| ⑥ | 방문 추적 스크립트 | hd-02 | 지움 — 기능과 무관 |
| ⑦ | 파비콘 절대주소 | HTML 41개 | 상대경로로 (+ **생성기도** 고침) |
| ⑧ | Google Drive 미리보기 | hd-06 | 누를 때만 부르게 + 안 되면 안내 |

**글꼴을 동봉하지 않은 이유**: Windows 는 맑은 고딕, macOS 는 Apple SD Gothic Neo 가
OS 에 반드시 있다. Pretendard 를 리포마다 넣으면 17MB 가 늘어나는데
얻는 것은 글꼴 모양 차이뿐이다. 한글이 깨지지 않는 것이 목적이고 그건 이미 된다.

**절대주소를 남긴 것**: `canonical`·`og:url`·`og:image` 는 그대로 뒀다.
브라우저가 받아 오지 않고(요청이 아니라 메타값이다), 카카오톡 공유 미리보기에는
절대주소가 반드시 필요하다. **파비콘만 다르다** — 실제로 받아 오므로 상대경로로 바꿨다.

## 밟은 함정 다섯

### 1. 소스 검사만으로는 못 잡는다 — hd-05 가 통째로 백지였다

소스 검사(`check-offline.mjs`)를 통과했는데 실제로 열어 보니 **0px·0자**.
React·Babel 주소를 변수에 담아 두고 실행 중에 `<script>` 태그를 만들어 붙이는
코드라 태그도 `import` 도 아니어서 어떤 규칙에도 안 걸렸다.

> 소스에 적힌 것만 보는 검사기는 "안 적힌 것"을 못 본다.

그래서 **바깥을 실제로 끊고 열어 보는** 탐침(`probe.mjs`)을 따로 만들었다.
검사기에는 "JS 문자열 속 CDN 이름" 규칙을 추가하고 **되돌려서** 잡히는지 확인했다.

### 2. `+esm` 번들은 자체 완결이 아니다

jsDelivr 의 `@supabase/supabase-js@2/+esm` 은 6.4KB 밖에 안 된다.
파일 안에서 auth-js·postgrest-js·realtime-js·storage-js·functions-js·node-fetch
**여섯 개를 더 불러온다.** 그것만 동봉하면 폐쇄망에서 그대로 깨진다.
파일 하나 챙기고 다 됐다고 여기기 딱 좋다. → UMD(110KB) 를 썼다.

### 3. 파일 이름을 짧게 지어 사진 세 장이 뭉갰다

unsplash 주소에서 `photo-([0-9a-f]+)` 로 이름을 뽑았는데
`photo-1556761175-b413da4baf72` / `-4b46a572b786` / `-5973dc0f32e7` 세 장이
전부 `1556761175` 가 되어 **14개 URL 이 13개 파일**이 됐다.
전체 식별자로 다시 받고 이름 충돌·개수·내용 중복을 assert 로 막았다.

### 4. 생성물만 고쳐서 되살아났다

파비콘 38개를 상대경로로 고쳤는데, **생성기(`og/inject.js`)를 안 고쳤다.**
16번 작업 때 그 생성기를 다시 돌리자 **38개가 전부 절대주소로 되돌아갔다.**

> 산출물 저장소에서 찾은 문제는 거기서 고치면 다음 생성 때 되살아난다.

생성기의 `favRoot` 를 폴더 깊이에서 계산하도록 바꾸고 왜 그런지 주석을 남겼다.

같은 회차에 **메타 블록이 두 겹**이 되는 문제도 나왔다.
`build.py` 가 쓰는 표식과 `inject.js` 가 찾는 표식이 미묘하게 달라서
자기 블록을 못 찾고 두 번째를 덧붙였다. 표식을 한 글자까지 맞췄다.

### 5. 검사기 기준이 빡빡해 멀쩡한 것을 잡았다

"글자 200자 이상"으로 잡았더니 hd-project07 이 걸렸다(141자).
접수 건이 없을 때의 빈 화면이라 원래 짧은 것이었고 앱은 멀쩡했다.

> 글자가 적은 것은 고장이 아니다. **하얀 화면**이 고장이다.

## 확인

**검사기를 일부러 깨뜨려 봤다** (통과만 본 검사기는 통과해도 의미가 없다)

| 넣은 것 | 결과 |
|---|---|
| 스타일시트 `<link>` | 🔴 잡음 |
| `<script src>` | 🔴 잡음 |
| `@import` | 🔴 잡음 |
| ES 모듈 `import` | 🔴 잡음 |
| JS 문자열 속 CDN 주소 | 🔴 잡음 |
| 바깥 `<img>` | 🟠 잡음 |
| 주석 속 URL | 안 잡음 ✔ (요청이 아니다) |
| 바깥 `<a href>` | 안 잡음 ✔ (사람이 눌러야 간다) |

**되돌려 확인** — hd-05 를 CDN 으로 되돌리니 백지(0px)로 돌아갔다.
고친 뒤에만 재면 원래 안 깨져 있었어도 통과한다.

**최종** — 바깥을 끊은 크롬으로 **29개 화면 전부**: 바깥 요청 0, 전부 정상 렌더.

## 남은 것 (의도한 것)

`hd-project10` 의 AI 문자인식 3종(`api.anthropic.com`·`api.openai.com`·`api.upstage.ai`)은
**사람이 눌렀을 때만** 부른다. 폐쇄망에서는 그 기능만 못 쓰고 화면은 정상이다.
같은 화면의 **Tesseract 문자인식은 동봉돼 있어 폐쇄망에서도 동작한다.**

`hd-06` 의 Drive 폴더 미리보기도 마찬가지 — 눌러야 부르고, 안 되면 안내가 뜬다.

## 도구

`hd-04/scripts/` — `check-offline.mjs`(소스 검사) · `probe.mjs`(실제로 열어 보기) · `README.md`

```sh
node scripts/check-offline.mjs "<dreamit-web 루트>"     # 빠른 소스 검사
python3 -m http.server 8899 &                          # 그 뒤
node scripts/probe.mjs /hd-05/ /hd-project07/app/ …    # 실제로 열어 보기
```

새 사이트를 만들거나 라이브러리를 추가할 때 **둘 다** 돌린다. 하나로는 판정이 안 된다.
