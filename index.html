STEP 1 · 실습

정적 웹페이지 만들기

HTML/CSS로 완성도 있는 랜딩 페이지를 만들고 GitHub Pages로 배포합니다. (hd-01, hd-02)

STEP 2 · 실습

데이터 연동 — Supabase

서버 없이 회원가입·로그인이 되는 웹사이트를 만들며 DB 연동을 익힙니다. (hd-03, hd-08)

STEP 3 · 실습

실전 페이지 & 대시보드

실제 서비스 수준의 페이지 클론과 협업 대시보드를 제작합니다. (hd-05, hd-06, hd-07)

STEP 4 · 프로젝트 (2일)

수강생 프로젝트 개발

각자 작성한 프로젝트 기획서를 Claude Code 작업 지시서로 변환해 실전 프로젝트 10종을 완성합니다. 실습을 더 다지고 싶은 수강생을 위한 복습 자료도 함께 제공합니다.
