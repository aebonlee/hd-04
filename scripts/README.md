# 폐쇄망 검사 도구

수업·실무 환경이 **인터넷이 끊긴 사내망**이므로, 화면이 바깥을 부르지 않아야 한다.
바깥을 부르는 태그 하나가 페이지 전체를 멈춘다. 폐쇄망에서는 요청이 거절되는 게
아니라 **응답 없이 기다리다 시간이 다 되어야** 끝나므로, 그동안 화면이 하얗다.
"안 열린다"로 보이지만 실제로는 열리는 중이라 원인을 찾기 어렵다.

## 두 가지를 함께 쓴다 — 하나로는 못 잡는다

### 1. 소스 검사 — 빠르다

```sh
node scripts/check-offline.mjs "<dreamit-web 루트>"          # 전체
node scripts/check-offline.mjs "<루트>" hd-05 hd-project07   # 일부
```

`🔴 막힘`이 하나라도 있으면 종료코드 1. 커밋 전에 돌린다.

**놓치는 것**: JS 가 실행 중에 만들어 붙이는 주소.
실제로 hd-05 가 그랬다 — React·Babel 주소를 변수에 담아 두고 나중에 `<script>`
태그를 만들어 붙이는 코드라 태그도 `import` 도 아니었다. 소스 검사는 통과했는데
폐쇄망에서 화면이 **통째로 백지**였다. 그래서 아래 ②가 필요하다.

### 2. 실제로 열어 보기 — 확실하다

```sh
cd "<dreamit-web 루트>" && python3 -m http.server 8899 &
node scripts/probe.mjs /hd-05/ /hd-project07/app/ …
```

`--host-resolver-rules` 로 **localhost 말고 전부 죽은 주소로 보낸 크롬**을 띄워
실제로 연다. 진짜 폐쇄망보다 가혹하다(거기선 기다리지만 여기선 즉시 거절된다).
**여기서 뜨면 폐쇄망에서도 뜬다.**

두 가지를 함께 본다. 하나만으로는 판정이 안 된다.
- 바깥으로 나간 요청이 있는가 → 0 이어야 한다
- 화면이 실제로 그려졌는가 → 요청이 0 이어도 하얀 화면이면 실패다

## 새 라이브러리를 쓸 때

CDN 주소를 적지 말고 파일을 `lib/` 에 넣고 그것을 가리킨다.

**⚠ jsDelivr 의 `+esm` 빌드를 그대로 동봉하면 안 된다.**
자체 완결이 아니라 그 안에서 또 바깥을 부른다. supabase-js 의 `+esm` 은
auth-js·postgrest-js·realtime-js·storage-js·functions-js·node-fetch 여섯 개를
더 불러온다. 파일 하나 챙기고 다 됐다고 여기기 딱 좋다. **UMD 빌드를 쓴다.**

## 절대주소를 남겨 두는 것

`canonical` · `og:url` · `og:image` 는 절대주소 그대로 둔다.
브라우저가 받아 오지 않고(요청이 아니다), 카카오톡 공유 미리보기에는 절대주소가
반드시 필요하다. **파비콘은 다르다** — 실제로 받아 오므로 상대경로여야 한다.
